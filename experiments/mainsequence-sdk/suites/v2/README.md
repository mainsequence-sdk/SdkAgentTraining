# MainSequence agent suite v2

This suite derives from v1 after the MainSequence SDK 4.x instruction-bundle
change. It targets SDK 4.4.5 and remains `pending_revalidation`.

The suite is versioned independently from repository snapshots. Existing
compatible units were migrated from v1 as a baseline, and every migrated case
must be checked against the locked SDK 4.4.5 instruction text before being
marked current.
